# Snacks.nvim Keymaps

## Picker — General

| Key | Description |
|-----|-------------|
| `<leader><space>` | Smart find files |
| `<leader>,` | Buffers |
| `<leader>/` | Grep |
| `<leader>:` | Command history |

## Picker — Files

| Key | Description |
|-----|-------------|
| `<leader>ff` | Find files |
| `<leader>fr` | Recent files |
| `<leader>fg` | Git files |
| `<leader>fb` | Find buffers |
| `<leader>fh` | Help pages |
| `<leader>fk` | Keymaps |
| `<leader>fd` | Diagnostics |
| `<leader>fc` | Commands |

## LSP

| Key | Description |
|-----|-------------|

## Notifications
