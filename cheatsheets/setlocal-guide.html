Windows setlocal Command

setlocal starts localization of environment changes in a batch file. Any variable changes after setlocal are reverted when endlocal is reached (or when the script ends).

Syntax

setlocal [EnableDelayedExpansion | DisableDelayedExpansion]

...commands...

endlocal

Basic Usage

@echo off
set VAR=global
echo Before: %VAR%

setlocal
set VAR=local
echo Inside setlocal: %VAR%
endlocal

echo After endlocal: %VAR%
Output shows that VAR returns to its original value after endlocal.

With Delayed Expansion

@echo off
setlocal EnableDelayedExpansion
set COUNT=0
for /l %%i in (1,1,3) do (
  set /a COUNT=!COUNT!+1
  echo Loop !COUNT!
)
endlocal

Use EnableDelayedExpansion when variables are updated inside loops/blocks and need to be read immediately.
